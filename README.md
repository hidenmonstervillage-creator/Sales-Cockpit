# Call Cockpit

Локален помощник за студени обаждания. Без бекенд, без акаунти, **нула мрежови заявки по време
на работа** — всичко се бъндълва локално и живее в `localStorage` под ключ `callcockpit.v1`.

Оптимизиран за десктоп (≥1280px). Езикът на интерфейса е български.

## Стартиране

```bash
npm i
npm run dev
```

Отваря се на http://localhost:5180

```bash
npm run build     # tsc --noEmit && vite build → dist/
npm run preview   # сервира dist/ на http://localhost:4173
npm run typecheck # само tsc --noEmit
```

## Данни

- Автозапис при всяка промяна в `localStorage`.
- **Експорт / Импорт JSON** (в горната лента) — целият стейт: кампании, скриптове, позиции на
  възлите, снимки, лийдове, логове. Това е единственият бекъп — прави го редовно.
- **Експорт / Импорт CSV** на лийдове, per кампания. UTF-8 с BOM, за да е четим в Excel.
- Метърът за място горе вдясно предупреждава над ~4 MB (снимките в възлите са най-тежки).

## Структура

| Път | Какво |
| --- | --- |
| `src/seed/autoclick.ts` | Seed кампанията „AutoClick — пътна помощ". **Текстът е финален** — не се пренаписва. |
| `src/lib/placeholders.ts` | Токен-енджинът (`[град]`, `[X]`, `[breakeven]`, `[номер]`, `[дата]`). |
| `src/lib/cadence.ts` | Каденцията: котва, стъпки, твърд стоп на крайния срок. |
| `src/lib/script.ts` | Мутации по графа (връзки, изтриване, позиции). |
| `src/lib/csv.ts` | CSV импорт/експорт + мапване на колони. |
| `src/script/ScriptPanel.tsx` | Платното (React Flow) + панелът за четене. |
| `src/views/` | Лийдове · Разговор · Опашка. |

Кампаниите са generic: полетата на лийда (`leadFields`), полетата за подготовка, статусите,
каденцията и скриптът се дефинират per кампания в **Настройки**.

## Деплой (Netlify)

Статичен сайт, без env променливи и без функции. `netlify.toml` в корена задава
`command = "npm run build"` и `publish = "dist"`.

- `public/_redirects` → SPA fallback, за да не 404-ва при refresh.
- `public/robots.txt` + `<meta name="robots" content="noindex, nofollow">` + `X-Robots-Tag`
  хедър — приложението държи реални контакти на лийдове и не бива да се индексира.
- `base: "./"` във `vite.config.ts` — относителни пътища до асетите.

**Важно:** деплойнатата версия и локалната са различни браузър origins, значи имат **отделни
localStorage**. Данните не се синхронизират — прехвърлят се само през Експорт/Импорт JSON.
Стампът горе вдясно (`dev …` жълто / `build …` сиво) казва коя версия гледаш.
